# Roadmap

- [ ] **M0 — Architecture and preparation:** inspect hardware/firmware, compare firmware options, select CCU integration strategy, document OTA and recovery.
- [ ] **M1 — CCU3 → NSPanel:** display at least one selected CCU datapoint and update it on change.
- [ ] **M2 — NSPanel → CCU3:** make physical button and touchscreen events available to CCU programs as sensor inputs.
- [ ] **M3 — Relays:** expose both relays as controllable actors with state feedback.
- [ ] **M4 — Productization:** configuration, error recovery, tests, diagnostics, packaging, documentation, OTA update workflow.

Milestones are goals, not claims of implemented functionality.
